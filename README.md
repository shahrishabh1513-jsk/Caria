## 📖 About The Project

**Caria (FashionHub India)** is a modern, responsive fashion e-commerce front-end where users can browse trending clothing, footwear and accessories, explore top brands, add products to a cart, and track their orders, all with a clean and colorful shopping experience.

> 💜 Built to showcase a complete online-store UI: from the landing page and product shop to cart, login, orders and order tracking.

## 🚀 Getting Started

### Run locally

```bash
# 1. Clone the repository
git clone https://github.com/shahrishabh1513-jsk/Caria.git

# 2. Go into the project folder
cd Caria

# 3. Open index.html in your browser
#    or use a local server (e.g. VS Code Live Server)
```

### Deploy on GitHub Pages

1. Go to **Settings → Pages** in your repository.
2. Under **Source**, choose the `main` branch and `/ (root)` folder.
3. Save, and your site will be live at `https://<username>.github.io/Caria/`.
